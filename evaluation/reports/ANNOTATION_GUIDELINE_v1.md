# 财务知识问答评测 · 标注规范 v1（Annotation Guideline）

> 版本：v1.0　冻结日期：2026-10-03
> 适用：`finance_eval_v1.csv`（45 题）中机器判错的 badcase 人工复核
> 由来：首次背靠背双标注 Kappa 只有 **0.346**（一致性偏低、不可用）；补齐本规范后 Kappa 升至 **0.693**。**这 0.35 的差距，就是"没有规范"的代价。**

---

## 1. 标注对象与输入

对每条机器判 `passed = False` 的题，读三个字段：

| 字段 | 作用 |
|---|---|
| `question` | 题目 |
| `golden_answer` | 标准答案要点（分号分隔的得分点） |
| `model_answer` | 模型原始回答 |

输出一个标签：`超纲` / `幻觉` / `误杀` / `真错`。

---

## 2. 四个类别的定义与判据

### 2.1 超纲 —— 错在题目，不在模型

**定义**：题目要求答出被测系统的**内部实现**（字段名 / 功能名 / 状态枚举 / 校验规则 / 配置口径），任何不了解该系统的领域专家都答不出。

**判据（规则 A · 资深领域专家测试）**
> 把这道题拿给一个**不给任何系统文档、但有 10 年本领域经验**的专家：他能答对吗？
> - 答不出、只能猜 → **超纲**
> - 能答对 → 说明是通用领域知识 → 模型没答对就是 **真错**

**正例（判超纲）**
- id19「盘点人策略的作用」——问的是产品自定义功能名
- id34「资产卡片数据检查功能的固定范围（已审核且非减少）」——系统固定条件
- id35「盘点中 / 已取回状态」——系统状态枚举

**反例（不算超纲）**
- id32「配置了折旧分摊但当期没生成分摊单的后果」——"费用归集未完成不能关账"是**会计常识，专家可推理** → 判 `真错`

---

### 2.2 幻觉 —— 编造了具体但不存在的信息

**定义**：模型对无法获知的信息，**编造出具体数值 / 年限 / 审批级次 / 字段名 / 规则名**，且语气自信、不表示不确定。

**判据**：能明确指认出它给出的那一条**在现实中不存在或无从查证**的具体信息。

**正例**
- id43：编造「500元 / 1000元」的阈值
- id44：编造「2-3 级」的审批级次
- id42：被问内部折旧率配置，不说"不知道"，反而列出具体率值

**反例（不算幻觉，属"错配 / 真错"）**
- id9：把「资产模块 ↔ 核算模块对账」答成"银行存款余额调节表"——**这个概念真实存在**，只是场景用错

> ⚠️ **为什么必须和"真错"分开**：两者管理动作完全不同。
> - 幻觉 → 加「不确定就明说不知道」的约束、上 RAG 补事实
> - 错配 → 补领域知识、在 prompt 里加领域边界

---

### 2.3 误杀 —— 错在判分器，不在模型

**定义**：模型语义上答对了，但没命中判分关键词。

**判据（规则 C）**：剥掉所有措辞，把模型答案"翻译"成标准答案的语言，意思**是否等价 / 是否包含**？
- 等价 or 包含 → **误杀**
- 只缺**非关键**得分点 → 仍可判误杀
- 缺的是**题目要问的那个核心点** → `真错`

**正例**
- id8：「系统进入下一个资产会计期间」≡「自动跳转到下一个账期」
- id29：「拆分前资产价值 = 各拆分后资产价值之和」≡ 标准答案

**反例（不算误杀）**
- id22：漏掉核心得分点「不参与折旧」——缺的是**题目的答案**，不是措辞 → 判 `真错`

> ⚠️ **禁止写法**：「意思达到了，但是不准确」——这是自相矛盾。不准确就不算误杀。

> ⚠️ **本条是实测撞出来才补上的（id12 争议）**
> 标注者写「误杀，基本答对，只不过措辞不准确」，但该题标准答案里有一条明确得分点：
> 「**价值变动也可以变动实物字段**」，而模型答的是「价值变动**仅**涉及价值属性字段」——
> 这是**明确说反了**，不是措辞问题。
> **判据收紧为**：先问一句——**缺掉/答反的那个点，是不是题目明确要问的得分点？**
> 是 → `真错`；只是非关键点的表述差异 → `误杀`。
> 「基本答对」不是判据，**必须落到具体得分点上说**。

---

### 2.4 真错 —— 模型确实答错

**定义**：语义上确实不成立 / 答非所问 / 关键得分点缺失。

**子类【错配】**：用了**真实存在但场景不对**的概念。
- id9：资产对账 → 银行存款余额调节表
- id13：资产转换（固资 ↔ 投资性房地产/融资租赁/使用权资产，会计准则里有明确定义）→ 答成"类别变更/状态变更"
- id15：处置流程 → 答成"报废/出售"

---

## 3. 标签优先级（一条题只能有一个标签）

```
超纲  >  幻觉  >  误杀  >  真错      （命中即停）
```

**理由**：超纲是"**题目本身的问题**"——题都不该问，就没必要再判模型了。

---

## 4. 标注流程（最小可运行版）

```
① 背靠背双标注（AI 初标 × 人工标注，互不通气）
        ↓
② 算一致率 + Cohen's Kappa
        ↓
③ Kappa < 0.6 → 逐条仲裁分歧，把仲裁理由回写进本规范
        ↓
④ 用新规范重标 → Kappa 上升 → 规范定稿冻结
        ↓
⑤ 抽检校准（每 20 条抽 1 条请第三方复核）
```

## 5. 本次实测结果（可复现，运行 `arbitrate.py`）

| 指标（24 条 badcase 全样本） | 数值 | 解读 |
|---|---|---|
| 双标注原始一致率 / Kappa | 58.3% / **0.476** | 中等一致，**未达 0.6 可用线** |
| AI 初标 vs 仲裁定稿 | 70.8% / **0.597** | 差一档到可用线 |
| **人工标注 vs 仲裁定稿** | **79.2% / 0.709** | 跨过 0.6 可用线 |

**结论 1（诚实记录）**：人工标注**比 AI 初标更接近仲裁定稿**（79.2% vs 70.8%）。AI 复核存在一个**系统性偏差**——把"领域机制题"判成 `真错`，本次共 7 条被仲裁推翻（id12/18/19/28/33/34/35）。**AI 倾向于高估模型能力，低估题目的超纲程度。**

**结论 2**：引入规范并完成仲裁后，人工标注与定稿的一致性达 **0.709**（较初始双标注 0.476 提升 **+0.233**）。这证明标注质量问题主要出在"**判据没对齐**"，而不是"标注员不认真"。
