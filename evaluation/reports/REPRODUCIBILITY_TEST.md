# 可复现性与温度对照实验记录

> 实验编号：EXP-2026-1013-02 ｜ 日期：2026-10-13 晚
> 模型：`Qwen/Qwen3-30B-A3B-Instruct-2507`（硅基流动）｜ 数据集：`ceval_benchmark100.csv`（100 题 × 7 科目）
> 脚本：`eval_choice.py`（同一 commit，仅改 temperature 与结果文件名）

## 一、实验设计

| 轮次 | temperature | 结果文件 | 目的 |
|---|---|---|---|
| 首跑 | 0.0 | `benchmark_qwen.csv` | 基线 |
| 轮 A | 0.0 | `benchmark_qwen_t0_rerun.csv` | 同配置重跑 → 测**可复现性** |
| 轮 B | 0.7 | `benchmark_qwen_t07.csv` | 改温度 → 测**温度是否为显著变量** |

其余全部锁定：`max_tokens=16`、system/user 提示词、题库与题序（CSV 原序不 shuffle）、判分口径（正则提取字母 + 精确匹配，PARSE_FAIL 不计入分母）、每题 1 次调用、不设随机种子。

## 二、结果

| 轮次 | 准确率 | parse_fail | 与首跑原始输出相同的题 |
|---|---|---|---|
| t=0.0 首跑 | **80.0%** | 0 | — |
| t=0.0 重跑 | **78.0%** | 0 | 96 / 100 |
| t=0.7 | **79.0%** | 0 | 96 / 100 |

三轮 parse_fail 均为 0 → 格式遵循度始终稳定，分差不是解析问题。

## 三、逐题差异（t=0 首跑 vs 重跑：4 题翻转）

| 题目 | 标准答案 | 首跑 | 重跑 |
|---|---|---|---|
| accountant#32（税务罚款滞纳天数） | C | C ✅ | B ❌ |
| accountant#44（金融行业工资率） | C | D ❌ | C ✅ |
| business_administration#26（长期股权投资） | A | A ✅ | B ❌ |
| tax_accountant#27（车船税） | B | B ✅ | D ❌ |

方向：3 题「对→错」、1 题「错→对」，净 −2 题 ＝ **−2.0pp**。

## 四、结论（面试可直接引用）

1. **`temperature=0` 不等于确定性。** 同配置重跑，100 题中 4 题答案改变，准确率波动 **2.0pp**。
2. **本次实验中温度的效应小于重跑噪声。** t=0→0.7 的分数变化（−1.0pp）**小于** t=0 自身重跑的波动（−2.0pp）→ 在这 100 题上，**温度不是显著变量，随机性是主导**。
3. **单次运行的分数是带噪声的估计，不是精确值。** 报告应标注波动区间或多次运行取均值，不要用单次结果下"模型 A 比 B 强 X%"的精确结论。
4. **误差集中在专业题。** 翻转的 4 题中 3 题属会计 / 税会 → 模型在**边界难度的专业知识题**上决策不稳定；简单题重跑仍稳定。

## 五、对已有报告口径的影响

用本次测得的**噪声量级（±2pp）**回看 `COMPARE_REPORT_v0.md`：

- DeepSeek 87.0% vs Qwen 80.0%，差 **7.0pp > 2pp** → 「DeepSeek 整体领先」**成立**。
- 分科目小差距（如会计 +3.6pp、编程 −12.5pp 等）中，**差距小于 2pp 的项落在噪声内，不能作为结论**。
- 21 道分歧题的归因方向（干扰项带走 / 多步推演少算一层 / 本土法规实务题）**不依赖单次运行**，仍然成立。

> 写法提醒：给出分数时应写成「80.0%（单次运行；同配置重跑波动约 ±2pp）」，而不是光写 80.0%。
